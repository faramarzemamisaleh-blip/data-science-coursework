# Data Science Coursework

Final projects from a comprehensive data science program (slides in Persian; summaries below in English).

## 1. Statistical analysis of employee salaries
Slides: [PDF (Persian)](statistics-salary-analysis/%D9%BE%D8%B1%D9%88%DA%98%D9%87%20%D9%86%D9%87%D8%A7%DB%8C%DB%8C%20%D9%81%D8%B1%D8%A7%D9%85%D8%B1%D8%B2%20%D8%A7%D9%85%D8%A7%D9%85%DB%8C%20%D8%B5%D8%A7%D9%84%D8%AD.pdf)
- Dataset: 411 employee records (salary, starting salary, education, job category,
  job time, previous experience, gender, minority)
- Methods: descriptive statistics and outlier analysis, normality tests, Z-test,
  two-sample t-tests and F-tests, Bartlett's test, one-way ANOVA, chi-square tests,
  correlation analysis, linear regression
- Finding: starting salary was the strongest predictor of current salary

## 2. Diabetes classification with IBM SPSS Modeler
Slides: [PDF (Persian)](diabetes-classification-spss-modeler/%D9%BE%D8%B1%D9%88%DA%98%D9%87%20%D9%86%D9%87%D8%A7%DB%8C%DB%8C%20%DA%A9%D9%84%D8%A7%D8%B3%20%D9%85%D9%81%D8%A7%D9%87%DB%8C%D9%85.pdf)
- Dataset: 768 records, binary outcome (Pima diabetes dataset)
- Data preparation: zero-value noise treatment, outlier detection (SD and IQR methods),
  missing-value imputation, automated data preparation, 80/20 train-test split,
  class-imbalance handling (oversampling / undersampling)
- Models compared: SVM, KNN, neural network, CRT, CHAID, QUEST, C5.0, Random Trees, Auto Classifier
- Result: the C5.0 decision tree gave the best balance between train and test accuracy
